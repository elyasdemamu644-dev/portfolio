# Elyas Demamu — Portfolio

A simple, hand-written HTML portfolio website for **Elyas Demamu**, a third-year Software Engineering student at Addis Ababa Science and Technology University.

The site is intentionally lightweight: plain HTML5 with a little inline CSS, no frameworks, no build step, and no dependencies.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Home page: about me, skills, featured projects, education and academic record, and contact details. |
| `projects.html` | Complete project list (16 projects) with descriptions, tech stacks, GitHub links, and a summary table. |

## Built with

- HTML5
- Inline CSS (no external stylesheet)
- No JavaScript frameworks, package managers, or build tools

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
